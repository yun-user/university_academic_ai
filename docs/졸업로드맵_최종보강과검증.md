## 브라우저·배포 검증

Codex 내부 브라우저의 React 화면에서 확인했다.

- 가상 8과목 → 21학점, 분류 미확인 전환 시 18학점 → 복원 시 21학점.
- 15/18학점 비교, 마지막 학기 9학점, 과목 이동 시 개설·상한 오류와 원상 복구.
- ‘시연용 · 보강 기능 검증’ 저장, 새로고침 후 불러오기, 기한 2026-11-09 유지.
- 전체 JSON 실제 다운로드 → 파일 선택 → 8과목·체크리스트 1개 미리보기 → 입력 교체. 학기별 15/15/15/9와 수동 배치 복원. 백업에는 키·LLM 대화·전송 동의 제외.
- 합성 14/14와 실제 평가 미실시 표시.
- 최종 화면의 390px·1280px 반응형 배치에서 문서 가로 넘침 없음, 브라우저 콘솔 오류 없음.

가상 예시의 실제 `gpt-4.1-mini` 응답에서 21학점 취득·111학점 부족을 반영한 기록이 있다. 실제 학생 성적은 쓰지 않았다. 한 응답으로 전체 정확도를 주장하지 않는다.

배포는 허용 목록의 코드·자료·문서·테스트·프론트 빌드만 포함한다. `.env`, 개인 DB, `node_modules`, 학생 성적은 제외하며 파일별 SHA-256은 `MANIFEST.sha256.json`에 기록한다. ZIP을 별도 폴더에 풀어 검증한 결과는 ZIP 옆 `verification-complete-20261007.json`에 남긴다. 같은 PC·기존 가상환경 검증은 새 PC 최초 설치를 대신하지 않는다.

## 실제 평가 계획

아래는 아직 실시하지 않은 평가의 설계다. ‘규정과 평가’의 폼과 시간 측정을 사용한다.

| 종류 | 사례 | 기록 |
| --- | --- | --- |
| 학교 기준 | 양 과정 정상, 재수강/F/수강중, 대체 승인/미승인, 설계 수강연도, 선수/병수 예외 | 학교 결과, 앱 결과, 과목별 차이, 공식 근거, 확인 여부 |
| LLM | 부족 요건, 추천/제외 이유, 마지막 학기 감축, 근거 없는 과목, 불명확한 승인 | 숫자·과목·출처 일치, 조건 위반, 근거 없는 단정, 설명 적절성 |
| 사용성 | 가져오기 → 수정 → 비교 → 저장/복원 | 완료 여부, 시간, 막힌 위치, 1~5 만족도, 익명 별칭 |

증빙이 없으면 미확인으로 남긴다. 기대값·관측값·근거·판정이 있어야 검증 완료로 저장할 수 있다. 평가용 개인정보는 기록하지 않는다.

## 제출 전 확인할 사항

1. 일반과정 최종 기준, 학과 내규 최신판, 공식 대체 승인표·MSC 인정 목록을 학과에 확인한다.
2. 양 과정 정상·예외 사례를 학교 졸업사정과 대조하고 실제 사용성·LLM 평가를 기록한다.
3. 교수자 평가표·제출 형식·영상 요구를 확인하고 다른 PC에서 `setup_web.cmd` 최초 실행을 시험한다.
4. 10월 중순 규정 확정·수정, 10월 하순 실제 평가, 11월 초 기능 고정·보고서·영상·복구 연습, 11월 9일 제출 순으로 마무리한다.

프로그램은 참고 계획을 제공한다. 공식 졸업 판정과 개별 승인은 학교에서 한다.
