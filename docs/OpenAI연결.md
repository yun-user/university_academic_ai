# OpenAI 연결

1. 프로그램 폴더의 `connect_openai.cmd`를 실행합니다.
2. 창의 **API 키 발급 페이지**에서 발급한 키를 입력란에 붙여넣습니다. 키를 채팅으로 보내지 마세요.
3. **연결 테스트 후 저장**을 누릅니다. `gpt-4.1-mini`에 짧은 시험 요청을 보내고 원문 인용·출처 형식을 검증합니다. 이 요청에는 API 이용료가 발생합니다.
4. 연결 성공 후 실행 중인 프로그램의 터미널에서 Ctrl+C로 종료하고 `start.cmd`를 다시 실행합니다.

Python에 GUI 구성요소가 없으면 콘솔 입력 창을 사용합니다. 이 경우 키를 붙여넣고 Enter를 누르세요. 입력한 키는 화면에 보이지 않습니다.

모델·공식 API 주소·활성화 설정은 자동 저장합니다. API 키는 이 PC의 프로그램 `.env`에 저장되며 Git과 배포 ZIP에 포함되지 않습니다. 관리자 비밀번호와 다른 기존 설정은 유지합니다. 실패하면 기존 설정을 변경하지 않습니다.

ChatGPT 구독과 별도로 OpenAI API 결제 설정이 필요합니다. 인증 실패는 키를, 사용 한도 오류는 API 잔액과 한도를 확인하세요.

이 시험은 합성 안내문으로 API와 출처 검증의 연결을 확인합니다. 전체 검색 품질을 평가하는 시험은 아닙니다. 실제 프로그램에서는 문서를 검색한 다음 그 근거만 OpenAI에 전달합니다. CSV 교과목 값은 기존의 정확한 표 답변을 사용하며, 근거가 없거나 API 호출이 실패하면 기존 검색 기반 답변을 유지합니다.

공식 문서: [API 시작하기](https://developers.openai.com/api/docs/quickstart), [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini)
