# 어학요건과 상담 캐릭터 (2026-10-08)

## 사용하는 방법

- 모든 화면 우측 상단의 움직이는 픽셀 캐릭터와 ‘상담이 필요하신가요?’ 말풍선을 누르면 AI 졸업 상담 입력창으로 이동한다. 이동 시 입력 내용은 유지된다. 캐릭터 움직임은 옆의 멈춤/재생 버튼으로 제어하며 운영체제의 동작 줄이기 설정을 따른다.
- 상담창은 Enter 전송, Shift+Enter 줄바꿈을 지원한다. 한글 조합 중 Enter는 전송하지 않는다. 답변을 기다리는 동안 픽셀 로딩 표시를 띄우고 중복 전송을 막는다. HTTP 오류 시 질문은 유지된다.
- ‘나의 졸업 현황 → 어학 성적과 제출 확인’에서 학과 공인시험 9종의 기준을 보고 시험·점수·유효기한·제출일·접수 확인을 입력한다. ‘어학 기준 확인’은 즉시 점검, ‘조건 적용하고 계산’은 전체 졸업현황에 반영한다.
- 성적표 유효기한은 직접 입력한다. 미입력·점수 형식 오류·지원하지 않는 척도·미래 제출일은 충족으로 처리하지 않는다. 유효기간 내 제출 및 해당 졸업에 대한 접수·인정을 사용자가 확인한 경우 제출일을 기준으로 대조한다.
- 기록은 SQLite 계획 저장·백업·복원에 포함되고, 계산 근거와 보고서에도 반영된다. 성적을 입력하면 기존 수동 어학 충족 상태보다 자동 대조 결과가 우선한다. 성적 입력이 없는 기존 계획은 기존 수동 확인을 유지한다.
- ‘저장한 계획 → 학과 졸업 준비 항목 추가’로 어학 점수, 성적표 제출, 졸업작품 결과물·발표, 개인별 필수과목 확인의 4개 항목을 추가한다. 기존 항목을 덮어쓰지 않으며 중복 추가를 막는다. 기한은 자동으로 지어내지 않는다.

어학 표는 **심화프로그램 기준**이다. 2018~2026학번 심화는 표의 2013년 이후 기준과 대조하며, 일반과정은 적용·예외 확인을 별도로 유지한다. TOEFL iBT는 표의 120점 척도, HSK는 4급 기준만 자동 비교한다. 다른 척도·급수는 ‘기타’로 선택하여 학과에 확인한다. 점수 충족만으로 공식 졸업판정을 하지 않는다.

AI 상담에는 동의한 경우에만 시험·점수·제출 확인 결과와 공통 규정 설명을 포함한다. 성적표 파일, 개인 이름, 실제 날짜는 자동 전송하지 않는다. 학교 계정 정보는 저장·전송하지 않는다.

## 검증

- 9개 시험의 기준 미만·동일·초과, 미입력·잘못된 점수·미래 제출일·만료·유효기간 경계, 일반과정 적용 보류, 기존 계획 호환, 출처 원본 변조 차단을 검사한다.
- HTTP API로 점검·졸업현황·근거 연결·SQLite 저장과 조회·JSON 백업 복원·보고서 출력을 합성 데이터로 검증한다.
- 프론트엔드 빌드와 기존 Enter/IME 단위 테스트를 실행한다. 실제 브라우저는 별도 로컬 모의 서버에서 검증한다. 외부 AI 답변 품질이나 학교의 실제 최종 승인에 대한 검증은 아니다.

최종 결과: 관련 Python 회귀검사 **303개 통과**, 프론트엔드 **7개 통과**, TypeScript/Vite 배포 빌드 성공. 실제 브라우저에서 캐릭터의 애니메이션 실행·멈춤·재생, 상담 입력창 초점 이동, Enter 전송과 로딩 종료, 어학 점수만 충족한 상태와 제출 확인 완료 상태의 구분, 체크리스트 4개 추가와 중복 방지를 확인했다. 검증은 개인 성적이 없는 합성 데이터와 로컬 모의 AI로 수행했다.
