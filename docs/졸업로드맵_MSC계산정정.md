# MSC 계산 정정

2026-10-08. 현재 클래스넷 인정과 2019.12 문서의 전산 상한을 대조하여, 적용 범위가 확인되지 않은 과거 제한을 모든 심화 학생에게 강제하던 동작을 수정했다.

## 변경 내용

- MSC 합계는 입력한 인정 이수구분의 수학·과학·전산을 더한다. 합계 아래에 분야별 계산식을 표시한다.
- 2019.12 내규의 전산 최대 6학점 문구는 역사적 근거로 유지하지만, 현재 개인별 적용이 확인되지 않아 기본 계산에 일괄 차감하지 않는다. 상한이 모든 학번에서 폐지되었다고 확정한 것은 아니다. 심화 전산이 6학점을 초과하면 클래스넷의 심화 MSC 인정학점과 대조하도록 안내한다.
- 명시적으로 범위가 정해진 `RuleSet.msc_computing_cap`을 사용하는 경우의 제한 처리는 유지한다.
- 공학기초수학(002144, 3학점)은 [2026 교과과정 책자(안)](https://ibook.hongik.ac.kr/Viewer/2026curriculum) PDF 37쪽(인쇄 35쪽) 교양과목 표에 근거해 교양선택으로 제안한다. 과목명에 ‘수학’이 있다는 이유로 MSC로 처리하지 않는다.
- 저장된 수동 입력은 자동 변경하지 않는다. **이수 과목 → 학과 자료로 분류 확인 → 해당 과목 선택 → 분류 적용** 후 다시 계산한다. 원본 보존에는 **저장한 계획 → 사본 저장**을 사용한다.

교양선택으로 정정한 학점에는 교양 인정 상한도 적용되므로 총 졸업인정학점이 함께 달라질 수 있다. MSC 합계에 더하거나 빼는 보정 상수를 넣지 않고, 과목 구분과 합산 규칙을 정정했다.

## 검증

- 전체 Python 테스트 **586개 통과, 46.21초**. 관련 회귀 테스트 **134개 통과**. 의존성 폐기 예정 경고 2건이 남아 있다.
- TypeScript 검사 및 Vite 빌드 통과. 합성 시나리오 **32/32 통과**.
- 가상 이수 내역에서 수학12 + 과학8 + 전산12 = MSC32를 2018~2026학번·심화/일반에 대해 확인했다. F·수강중·인정제외는 합산하지 않는다. 명시적 전산 상한이 있는 별도 규정은 MSC만 제한하고 총 취득 합계를 보존한다.
- 공학기초수학의 정확한 코드·이름·학점 분류, 수동 값의 미선택 보존, 교양 상한 반영을 검사했다.
- 로컬 브라우저에서 실제 학교 분류와 대조 후 한 과목만 선택 적용, 재계산, 사본 저장, 새로고침·불러오기를 확인했다. 분류 외 성적·수강시기·계획 조건 보존을 로컬 DB에서 대조했다. 개인별 수치·성적표·DB·화면은 공개 자료에 포함하지 않았다.
- 웹 배포 ZIP과 실제 실행 폴더의 파일 해시를 대조하고, 배포 폴더에서도 관련 테스트 **134개**를 통과했다. 배포본은 `output/planner/graduation-roadmap-msc-20261008.zip`이며 개인 DB·API 키는 포함하지 않는다.

이 검증은 발견된 계산 오류와 구현의 회귀를 점검한 것이다. 모든 학생의 공식 졸업판정 정확도를 입증하지 않으며 개별 면제·대체·인정 범위는 학교 확인이 필요하다.
