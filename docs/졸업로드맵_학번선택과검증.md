# 2018~2026학번 선택과 검증

2026-10-08 갱신. 기존 2020학번 고정을 해제하고 React·Streamlit·REST API·DB·LLM 문맥·보고서·평가 기록에 입학연도를 전달한다. 2027학번 이후는 검토 자료를 확보하기 전까지 지원하지 않는다. 수강연도와 입학연도는 별개다.

## 사용 방법

1. ‘나의 졸업 현황’ 상단에서 **입학연도 (학번)**와 **이수 과정**을 선택한다.
2. 적용 기준 카드의 영역별 학점과 원본 쪽수를 확인한다.
3. 이수내역을 가져와 이수구분을 확인하고 계산한다. 2022학번 이후 SW·데이터는 과목 상세의 인정학점도 확인한다.
4. 학번을 바꾸면 기존 과목은 유지한다. 승인·대체인정 확인, AI 전송 동의·상담은 초기화되며 수동 배치는 자동 계획으로 전환한다. 남긴 개인 필수목록의 적용 여부도 다시 확인한다.
5. 저장한 계획 목록과 보고서에도 학번이 표시된다. 새로고침 후에는 저장한 계획을 불러온다.

## 적용한 차이

공통으로 총학점 132, 전문교양 23, 전공기초영어 2학점이다. 심화는 전공54·MSC30·설계12·교양인정상한40, 일반은 전공50·MSC27·교양인정상한50을 사용한다.

| 학번 | 특성화교양 | SW·데이터활용 | 일반 MSC 수학/과학/전산 | 일반 과학 지정 조건 |
| --- | --- | --- | --- | --- |
| 2018 | 별도 필수 없음 | 별도 필수 없음 | 3 / 8 / 0 | 물리(1)·물리실험(1)·화학(1)·화학실험(1) |
| 2019 | 3 | 별도 필수 없음 | 3 / 8 / 0 | 위와 같음 |
| 2020~2021 | 3 | 별도 필수 없음 | 3 / 8 / 2 | 위와 같음 |
| 2022~2023 | 3 | 9 | 3 / 8 / 2 | 위와 같음 |
| 2024~2026 | 3 | 9 | 3 / 4 / 3 | 물리 이론·실험 또는 화학 이론·실험 한 세트 |

심화는 대학 공통 분야별 최소과목 기준과 학과 자료를 함께 사용한다. 2018~2020학번은 학과 표의 물리(1)·물리실험(1)을 검사한다. 2021학번 이후는 대학 공통의 실험 포함 한 세트를 참고 점검하되 **학과 과학 지정과목 확인**을 미확인으로 남긴다. 다른 계열의 이론과 실험을 섞어 한 세트로 인정하지 않는다. 세트 이수율은 0·0.5·1로 계산하여 학점 최소값을 이미 채웠더라도 부족한 세트의 첫 과목을 추천할 수 있게 했다.

SW·데이터 인정학점은 과목 학점을 초과할 수 없다. 전공·교양 등 원래 이수구분은 유지하며 SW·데이터 영역에서만 별도로 점검하고 총학점에는 한 번 합산한다. 자동 가져오기는 이 값을 추정하지 않는다. 지정 과목과 다른 영역의 중복 인정은 학교 확인이 필요하다. 기존 CSV와 백업에 해당 필드가 없으면 0으로 복원한다.

## 자료의 확정 범위

- `config/reviewed_rules/aid_college_2026.json`: 원본 PDF 8~14쪽의 학번 경계·학점표 대조. 원본은 `sources/aid_graduation_credits_2026_p8-16.pdf`에 보관하며 해시를 검사한다.
- [2026 교과과정 뷰어](https://ibook.hongik.ac.kr/Viewer/2026curriculum), 클래스넷 → 졸업정보 → 졸업요건 조회 → 교과과정 적용원칙 및 졸업학점 현황.
- 학과 졸업기준 표의 직접 확인 범위는 2020학번까지다. 이후 학번의 학과 지정과목·개별 면제는 학교 확인이 필요하다.
- 2026 이수체계도의 선수·병수는 수강연도 기준이다. 입학연도를 바꾸어도 공식적으로 입력한 선수 관계를 자동 해제하지 않는다.
- 2019.12 학과 내규의 MSC전산 인정 상한 6학점은 심화 참고 계산에 유지하며 최신 개정 확인을 표시한다.

2026 교과과정 원본 파일은 ‘안’ 표기가 있다. 이 구현은 확정된 학교 졸업사정이나 실제 학생 정확도 평가를 대신하지 않는다. 편입·전과·복수전공은 지원 범위 밖이다.

## 검증 기록

- 전체 Python 자동 테스트: **512개 통과, 35.99초**, 의존성 폐기 예정 API 경고 2건.
- TypeScript 검사·Vite 배포 빌드 성공.
- 합성 시나리오 **32/32** 통과 (기존14 + 학번·과정 조합18).
- API의 전체18조합, 범위 밖 학번 거절, 과학 혼합 세트 거절, 세트 보완 추천, SW 학점 중복합산 방지, 기존 CSV·백업 호환을 검사했다.
- AI 상담 및 추천 문맥, HTML 보고서, 계획 비교, 평가 기록에 선택 학번이 전달되는 것을 검사했다. 이번 변경의 LLM 검사는 공급자 모의 응답을 사용했다.
- SQLite v2 형식의 실제 테이블을 생성해 v3 이전 후 ID·소유자·과목·이력·리비전 보존, 반복 초기화, 학번 변경 저장, 외래키 삭제를 검사했다. 실행 중인 로컬 DB도 이전 전에 별도로 백업했다.
