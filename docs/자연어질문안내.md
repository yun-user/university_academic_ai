# 자연어 질문 안내

졸업 관련 질문은 아래처럼 입력할 수 있습니다. 문장 전체가 예시와 같을 필요는 없습니다.

- 소프트웨어융합학과 졸업요건이 뭐야?
- 소프트웨어 융합 학과의 졸업 요건을 알려 주세요
- 졸업하려면 뭘 해야 해?
- 전공 얼마나 들어야 돼?
- 졸업하려면 총 몇 학점 필요해?
- 졸업하려면 토익 몇 점 필요해?
- 설계 학점은 얼마나 들어야 졸업 가능해?

학과명과 질문 주제를 인식해 전체 조건 또는 해당 항목의 답변을 선택합니다. 학과를 생략하면 선택된 학과를 사용합니다. 등록된 개별 학과가 하나이면 해당 학과를 기본으로 사용하고, 여러 학과 중 선택되지 않았다면 학과 선택을 안내합니다. 질문에 명시한 학과가 화면 선택보다 우선합니다.

숫자와 요건은 원문에 연결된 검토 요약을 사용합니다. 현재 요약의 근거는 2019년 심화과정 내규이며, 최신 졸업요건이나 개인의 졸업 가능 여부를 확정하지 않습니다. 졸업식, 사진, 취업, 졸업프로젝트 과목 질문에는 졸업요건 표 요약을 사용하지 않습니다.

이번 개선은 졸업 관련 표현 인식과 답변 항목 선택을 보강합니다. 모든 한국어 표현이나 등록되지 않은 사실에 답할 수 있다는 의미는 아닙니다. 대화 이전 질문의 학과·입학연도를 자동으로 추론하지 않으므로 화면에서 학과를 선택하거나 질문에 적어 주세요. OpenAI API 없이 사용할 수 있습니다.

검증: 전체 테스트 166개 통과, 실제 색인으로 자연어 질문 7개 확인. 변경된 문서에는 원문 해시가 다른 이전 요약을 재사용하지 않습니다.
