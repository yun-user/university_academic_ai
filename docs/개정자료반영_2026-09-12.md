# 개정 자료 반영 및 검증

## 변경 결과

졸업요건 질문에 예전 2019년 PDF의 표 요약이 먼저 반환되던 경로를 보강했다. 소프트웨어융합학과의 검토된 학과 졸업표와 2024년 어학 대체교과목 삭제 공지를 함께 사용한다. 일반 검색·교과목 조회·LLM 호출 경로는 기존 기능과 함께 유지된다.

- `소프트웨융합학과 졸업할려면 뭐뭐 해야해?`: 유일하게 일치하는 등록 학과명 오타를 보정하고, 학과 심화과정 표와 어학 개정 공지를 함께 안내한다.
- `실용영어로 토익 대체 가능해?`: 2024학년도 2학기부터 이수 시 인정 불가라는 공지 및 실제 이수학기 확인 필요를 안내한다. 입학연도를 수강연도로 사용하지 않는다.
- `2020학번 심화과정 MSC 몇 학점 필요해?`: 검토한 학과 표의 총 30학점, 과학 4·수학 3·전산 3학점 조건을 안내한다. 대학 내규의 예전 수치와 구분한다.
- `2023학번 졸업요건`: 확인된 학과 표에 해당 학번 열이 없어 학점 확정을 보류한다.
- `일반과정 졸업요건`: 심화과정 학점표를 일반과정에 적용하지 않고 추가 자료 필요를 안내한다.

## 사용법

1. 실행 중인 앱을 종료한 뒤 `start.cmd`로 다시 실행한다.
2. 학과와 질문을 입력하고, 알면 입학연도·졸업 과정을 선택한다. 모르는 조건은 미선택 상태로 둔다.
3. 질문에 직접 쓴 입학연도·과정이 선택 상자보다 우선한다.
4. 이번 규정 답변은 기본 근거 기반 모드가 정상이다. LLM이 수동 검토한 숫자와 개정 조건을 다시 바꾸지 않게 했다. 다른 질문의 LLM 연결 설정은 유지한다.
5. 이 업데이트의 검토 자료는 별도 참조 번들이므로 벡터 재색인 없이 적용된다.

이 번들은 코드 배포에 포함되는 고정 참조 자료이며 현재 관리자 업로드 문서의 비활성화 기능과는 별도로 관리한다. 개정 시 원문 확인, 전사·적용 범위·요약 수정, 해시 갱신, 회귀 테스트를 함께 수행해야 한다. 새로운 자료를 발견했다고 예전 규정의 모든 조항이 일괄 대체된 것으로 처리하지 않는다.

학과 표는 게시·개정일 미표시이며 파일명의 2022를 시행연도로 보지 않는다. 표의 확인 범위를 벗어난 학번, 2024년 이후 후속 개정, 편입·전과·복수전공 등의 특례는 추가 자료가 필요하다.

## 검증

Windows / Python 3.12에서 전체 189개 테스트 통과. 신규 19개는 어학 대체 폐지, 수강/입학연도 구분, 적용 대상 이탈, 원본 변조, 타 학과·문서 필터, LLM의 검토 답변 보존, 실제 검색 서비스 경로와 화면 선택값 전달을 점검한다. 독립된 실제 학생 질문 정확도 실험으로 해석하지 않는다.

## 졸업과제의 다음 준비

개정 공지를 놓친 문제와 개선 결과는 보고서·발표의 구체적 사례로 활용할 수 있다. 추가 기능을 늘리기 전에 학생 자연어 질문을 모아 정답과 근거를 별도로 검토하고 검색/답변/출처 정확성을 나누어 측정한다. 보고서에는 범위 밖 질문을 보류하는 동작과 남은 한계도 기록한다.

개인 클래스넷 수업계획서, 수업 일정, 개인정보, API 키는 배포 자료에 포함하지 않는다.
