# 2026-10-03 코드 검토·수정·실행 결과

## 범위와 작업 방식

앱과 관리자 페이지, 설정·시작 스크립트, PDF/CSV/TXT 수집, OCR 검토, 문서 저장·색인, 키워드/의미 검색, 규정·과목 답변, LLM 인용 검증, 평가 코드와 관련 테스트를 검토했다. 기존에 작업 중이던 변경 사항은 유지했다. 이번 작업에서 원본 자료나 `.env`를 수정하지 않았으며 외부 LLM API는 호출하지 않았다.

## 수정한 문제

| 문제 | 수정과 검증 |
| --- | --- |
| 조기졸업 질문이 학과의 일반 졸업표로 분류됨 | 학교 학사안내 경로를 먼저 적용하고 조기졸업·학위취득유예를 일반 졸업표 분류에서 제외했다. 빈 색인에서도 검토된 안내 자료를 조회한다. |
| CSV 중복 열 이름이 다른 열 이름과 충돌해 값이 유실됨 | 명시된 열 이름까지 예약하고 충돌하지 않는 접미사를 선택한다. 중복·빈 열 이름 조합을 테스트했다. |
| PDF 일부 페이지 추출 실패 후 불완전한 자료가 정상 corpus를 대체할 수 있음 | 페이지 읽기·추출 실패를 파일 오류로 처리하고 실패 결과를 별도 저장한다. 기존 corpus 보존과 실패 페이지 번호를 검증했다. |
| 긴 CSV 행의 분할로 과목명과 학기별 정보가 분리됨 | CSV 한 행을 하나의 검색 단위로 보존한다. 작은 청크 크기에서도 과목 조회 결과를 검증했다. |
| 2학기 학수번호 조회에 1학기 정보가 표시되거나 조건이 무시됨 | 학수번호가 속한 학기의 학점·시수를 선택하고 학년·학기·이수구분 조건을 정확 조회에도 적용한다. 조건 불일치는 확인 안내로 응답한다. |
| 이수구분 없는 학년·학기 질문이 상위 3개 과목만 반환함 | 학년과 학기만 있어도 구조화된 전체 목록 조회를 사용한다. 실제 2학년 1학기 질문에서 7개 과목과 행 출처를 확인했다. |
| 이름·페이지가 같은 서로 다른 재수강 규정의 적용 범위가 합쳐짐 | 규정 중복 제거와 묶음 키에 문서 ID를 포함해 서로 다른 입학연도의 근거를 보존한다. |
| 환경 변수의 NaN/Infinity가 수치 설정으로 허용됨 | 유한한 수인지 검사하고 잘못된 설정은 거부한다. |
| 평가 질문에 `학수번호 부학기`가 생성됨 | 학기 표기를 제외하고 두 학기에서 유효한 식별자를 찾는다. 해당 기존 평가 질문을 `704814`로 바로잡았다. |
| Streamlit 파일 감시가 Transformers의 선택적 이미지 모듈을 불필요하게 로딩함 | 기본 파일 감시를 끄고 코드 수정 후 재시작하도록 안내했다. |

## 실행 결과

- 최초 자동 테스트: **275 통과, 1 실패**. 조기졸업 분류 실패를 재현했다.
- 수정 후 전체 자동 테스트: **303 통과** (`python -m pytest -q`).
- 패키지 의존성 검사: `python -m pip check` 통과.
- `git diff --check`: 통과. Windows 줄바꿈 변환 안내만 출력됐다.
- 실제 전처리·색인: `python -m scripts.prepare` 성공. 9개 입력 파일, PDF 295쪽, CSV 57행, corpus 353레코드, 검색 가능한 5개 문서·1,774개 문단.
- 전처리 오류 0건. 참고용 XLSX 제외 1건, 이미지 페이지 7건, 빈 페이지 6건, 직접 추출 가능한 텍스트가 없는 PDF 4건의 경고는 남아 있다. OCR 검토·승인 없는 이미지 자료를 검색 가능 자료로 간주하지 않았다.
- 실제 브라우저에서 조기졸업 안내와 출처, 2학년 1학기 전체 과목 7개, 학수번호 `704814`의 종합설계(2)·3학점·시수 4·CSV 47행 출처를 확인했다.
- 테스트용 서버: `http://127.0.0.1:8502`. 기본 시작 스크립트의 포트는 8501이다.

## 남은 확인 범위와 운영 안내

- 별도 CLI에서 색인을 갱신한 뒤 실행 중인 앱의 기존 Chroma 연결에서 검색 오류가 재현됐다. **앱 종료 → `python -m scripts.prepare` → 앱 재시작** 순서를 사용한다. 재시작 후 실제 화면에서 정상 검색을 확인했다. 프로세스 간 잠금은 접근 순서를 제어하지만 각 프로세스의 메모리 캐시를 갱신하지 않는다.
- 외부 LLM의 실제 API 연결·과금·모델 응답 품질은 이번 실행에 포함하지 않았다. 인용 검증과 실패 전환은 자동 테스트로 확인했다.
- 스캔 자료의 OCR 원문 대조와 승인, 새로운 입학연도·과정의 공식 근거 확인은 별도 자료 검토가 필요하다. 검토되지 않은 범위까지 지원한다고 표시하지 않았다.
- 배포용 ZIP이나 릴리스 매니페스트는 이번 검토에서 새로 만들지 않았다. 현재 폴더의 코드와 로컬 실행 결과에 대한 검증이다.
