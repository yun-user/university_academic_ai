# 설계학점 답변 수정

확인일: 2026-09-12

## 문제와 원인

‘설계학점 12학점에는 어떤 과목이 포함돼?’가 교과목 검색으로 분류되어 관련도 상위 3개 과목만 반환됐다. 이 값은 교과과정의 일반 학점이었으며, 과목별 공학인증 설계 인정학점 목록과 구분되지 않았다. 창의적공학설계입문·종합설계(1)·종합설계(2)만으로 12학점이 충족되는 것처럼 보이는 불완전한 답변이었다.

## 확인한 공식 자료

- 학과 설계/대체 교과목: https://software.hongik.ac.kr/home/templates/curriculum/courses
- 학과 교과과정: https://software.hongik.ac.kr/home/templates/curriculum/curriculum

설계교과목 페이지에는 2015년까지, 2016년, 2017년, 2019년 이후 표가 있으며 학번과 관계없이 수강연도에 따라 적용한다고 명시한다. 2019년 이후 표에는 창의적공학설계입문 2, 종합설계(1) 3, 종합설계(2) 3 외에도 알고리즘및실습 1, 머신러닝및실습(2) 1, 디자인패턴프로그래밍 및 실습 2, 네트워크실험 1, 소프트웨어공학 1, 컴퓨터보안 1, 데이타베이스및실습 1, 통신시스템실험 1, 오픈소스소프트웨어 1 설계학점이 기재되어 있다.

합산 예: 세 과목 8 + 디자인패턴 2 + 알고리즘 1 + 소프트웨어공학 1 = 설계 12학점. 이 조합이 유일하거나 개인 졸업요건 전체를 충족한다는 뜻은 아니다. 과목의 전체 학점과 설계 인정학점을 동일하게 취급하면 안 된다.

## 변경

- 설계학점에 포함되는 과목·인정학점 질문을 규정 조회로 분류한다.
- 상위 3개 검색 결과 대신 검토된 2019년 이후 설계 인정학점 전체 표와 공식 URL을 제시한다.
- 수강연도가 2019년 이전이라고 명시되면 해당 연도 표 추가 확인을 안내한다. 입학연도를 수강연도로 추정하지 않는다.
- 총 설계학점 요구 조건은 본인의 학번·과정에 따라 따로 확인해야 한다고 표시한다.
- 교과과정 원본의 ‘부학기’ 표기를 숫자 학수번호처럼 답하지 않는다. 특정 학기를 요청하지 않았다면 실제 코드가 있는 학기의 정보를 선택한다. 종합설계(2)는 기존 CSV의 2학기 코드 704814로 표시한다. 1학기를 명시하면 ‘미지정(원문: 부학기)’라고 표시하며 코드를 추정하지 않는다.

설계 원문 HTML은 config/reviewed_rules/sources/design_courses.html에, 검토한 구조화 표는 config/reviewed_rules/design_courses.json에 보관한다. 원본 해시를 검증한 뒤 답변하며, 변경·손상된 원문은 재검토가 필요하다. 2019년 이전 표는 이번 구조화 대상에 포함하지 않았다.

## 검증

전체 214개 테스트 통과. 사용자의 정확한 질문과 표현 변형, 전체 12개 과목, 8학점과 추가 4학점, 입학연도와 수강연도 구분, 원문 변경 시 보류, LLM의 검토값 보존, 학기별 코드 선택을 점검했다. 기존 실제 색인으로도 해당 질문과 종합설계(2) 조회의 코드 704814 표시를 확인했다.
