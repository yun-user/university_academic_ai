- 전체 자동 테스트: **127 passed**. 기존 88개와 업로드·활성화·버전 보존·한국어 검색·출처 검증·LLM 오류 전환·웹 주소 제한·robots·OCR 승인·관리자 화면·평가 지표 검증을 포함합니다.
- `pip check`: 의존성 충돌 없음.
- 실제 입력: PDF 7개 / CSV 1개 / TXT 1개. PDF 295쪽, CSV 데이터 57행.
- 전처리: 오류 0건. 이미지 PDF·미지원 참고용 XLSX 등 경고는 보고서에 남깁니다.
- 실제 임베딩 모델: `intfloat/multilingual-e5-base`, CPU. 실제 색인 1,774개 청크, 검색 가능한 문서 5개. 스캔 PDF 4개는 OCR 검토·승인 전이므로 기본 색인에서 제외됩니다.
- OCR: 기존 설계교과목 스캔 PDF 1쪽에서 한국어 텍스트 추출을 실제 실행했습니다. 미승인 상태로 보존했습니다.
- 브라우저: 로컬 Streamlit 앱 실행, 1,774개 검색 문단 표시, `학수번호 001009 교과목 정보`의 영어 과목·학점·시수·CSV 출처 표시를 확인했습니다.
- HTTP 상태 점검: `/_stcore/health` 응답 `ok`.
- 실제 외부 LLM API 호출: 수행하지 않았습니다. API 키·모델 선택은 사용자가 설정하며, provider 계약과 오류 경로는 가짜 provider로 검증했습니다.
- 웹 수집: 본문 추출·robots 차단·도메인 이탈·비공개 IP 차단 자동 테스트를 수행했습니다. 모든 학교 게시판의 CSS 구조와 수집 허용 여부를 보장하지 않습니다.

## 구현상 남는 한계

- OCR 검토는 페이지 단위 수동 승인입니다. 표 구조의 완전 자동 복원을 제공하지 않습니다.
- 공개 공지는 개별 본문 URL 단위로 수집하며 사이트별 선택자가 필요할 수 있습니다.
- 입학연도 메타데이터를 보존하지만 규정의 모든 예외와 적용 범위를 자동 확정하지 않습니다.
- 근거가 없는 질문 거절률은 단 6개 범위 밖 회귀 질문의 결과입니다.
- 앱은 로컬 시연·개발용입니다. 학교 운영 환경에 대한 보안·부하·배포 검증은 포함하지 않았습니다.
