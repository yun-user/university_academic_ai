# 화면 이동·학기 추가·픽셀 도우미

2026-10-08. React 웹앱의 버튼 목적지와 스크롤·키보드 초점을 함께 정리했다.

| 버튼 | 동작 |
| --- | --- |
| 졸업 현황의 현황 계산·이수구분 확인·이수 과목 입력 | 이수 과목의 이수 내역 제목으로 이동 |
| 이수 내역의 졸업요건 계산 | 성공하면 졸업 현황으로 이동. 실패하면 이수 과목 화면을 유지하고 오류로 이동 |
| 전체 점검 보기 | 졸업 현황의 전체 졸업요건 점검으로 이동 |
| 전체 로드맵 보기 | 학기별 로드맵의 학기별 결과로 이동 |
| 계획 조건 변경 | 졸업 현황의 계획 조건으로 이동 |
| 메뉴·저장 관리·저장 계획 불러오기·예시 불러오기 | 해당 화면 제목으로 이동. 입력과 상태는 기존 저장 규칙을 유지 |
| 이수 표 적용·백업 복원 | 이수 내역으로 이동해 입력을 검토 |
| 과목 추가·상세 편집 | 상세 편집의 학수번호 입력칸으로 이동. 닫기는 원래 행으로 초점 복귀 |
| 상담 추천 질문 | 질문을 채운 후 질문 입력칸으로 이동 |

학기별 로드맵의 **계획 비교와 직접 수정 → + 한 학기 추가**를 누르면 한 학기씩 늘어나고 다시 계산한다. 기존 개별 한도와 직접 배치는 보존한다. 새 학기는 기본 학점 한도를 사용하며, 과목 이동 선택지와 저장·백업에도 반영된다. 최대 12학기 및 2100년 2학기 제한에 도달하면 추가 버튼을 비활성화한다. 졸업 현황에서 학기 수를 조절할 때도 앞 학기의 개별 한도를 보존한다.

**나에게 맞게 추천받기**와 **AI 졸업 상담**에 책을 읽는 픽셀 도우미를 추가했다. 눈 깜빡임·작은 움직임과 AI 요청 중 독서 동작을 CSS로 표시한다. SVG를 코드로 그려 이미지 서버나 추가 네트워크 요청이 필요 없다. 정지·재생 버튼이 있으며 운영체제의 동작 줄이기 설정에서는 기존 접근성 CSS에 따라 움직임을 멈춘다. 애니메이션 추가는 LLM 응답이나 학점 계산 규칙을 변경하지 않는다.

## 검증

- TypeScript 검사와 Vite 배포 빌드 통과.
- `cd frontend` 후 `npm test`: 학기 확장·개별 한도·0학점 학기·연도 경계·기존 입력 보존 테스트 4개 통과. 테스트 실행에는 Node.js 22.18 이상을 사용한다.
- 관련 API 회귀 테스트 25개 통과. 학기 확장 후 수동 배치·한도·저장·복원 검증 포함. 의존성 폐기 예정 경고 2건.
- 실제 브라우저에서 가상 8과목으로 왕복 이동, 계산 실패 시 화면 유지·오류 초점, 4→5→6→7학기 연속 추가, 15·0학점 한도 보존, 수동 배치 29과목 보존, 이동 선택지 7개 반영, 12학기 추가 제한을 확인했다.
- 두 AI 메뉴의 픽셀 표시, CSS 애니메이션의 재생·정지, 추천 질문 초점, 저장·규정 메뉴, 과목 추가·상세 편집·닫기 동선을 확인했다. 브라우저 콘솔 오류 없음. 실제 외부 LLM 호출은 하지 않았다.
- 기존 학생의 저장 사본을 변경 없이 불러와 이수 내역과 계산 결과가 유지되는지 확인했다. 가상 UI 검증은 학생 DB에 저장하지 않았다.

실행 폴더는 `output/planner/graduation-planner`, 새 배포본은 `output/planner/graduation-roadmap-navigation-20261008.zip`이다. 배포 파일만 갱신하며 개인 DB·가상환경·API 키는 보존하고 ZIP에는 넣지 않는다.
