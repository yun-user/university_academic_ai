# 학과 검색 수정

질문에 학과명이 있으면 해당 학과 메타데이터로 검색을 제한합니다. 학사 규정 검색에서 `전체` 자료를 자동으로 포함하던 동작을 제거했습니다. 질문의 학과명은 화면의 학과 선택보다 우선하며, 학과명 내부의 띄어쓰기를 허용합니다. 등록되지 않은 학과명도 필터로 유지해 다른 학과의 답변으로 대체하지 않습니다.

실제 “소프트웨어융합학과 졸업요건” 검색에서 디자인엔지니어링 규정이 제외되고 모든 결과의 학과가 소프트웨어융합학과임을 확인했습니다. 전체 테스트 136개 통과. API 호출 없이 검색 및 기존 답변 경로를 검증했습니다.

검색 범위는 등록된 학과 메타데이터에 의존합니다. 전체 공통 규정은 학과를 지정하지 않은 질문으로 별도 검색하세요. 기존 자료의 기준연도와 최신 여부는 그대로 표시됩니다. 자료 내용을 최신 졸업요건으로 갱신한 변경은 아닙니다.

적용 후 실행 창에서 Ctrl+C로 종료하고 start.cmd를 다시 실행하세요. 기존 질문은 다시 검색해야 합니다. 재색인은 필요하지 않습니다.
